# Data Explorer - Students Performance Dataset

## Dataset

Students Performance Dataset containing information about students and
their exam scores.

## Observations

- The dataset contains 1000 rows and 8 columns.
- It contains both categorical and numerical data.
- The numerical columns are math score, reading score and writing score.
- There are no missing values in the dataset.
- Pandas was used to inspect the shape, column names, data types and
  summary statistics.
