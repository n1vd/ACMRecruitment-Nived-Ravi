# Data Refinery - Students Performance Dataset

## Data Cleaning Approach

I cleaned the Students Performance Dataset using Pandas.

### Steps Performed

1. Loaded the dataset using Pandas.
2. Checked all columns for missing values.
3. Removed rows containing missing values, if any.
4. Checked the dataset for duplicate records.
5. Removed duplicate records.
6. Verified that the cleaned dataset had no remaining missing values or duplicates.
7. Saved the cleaned dataset as `cleaned_students_performance.csv`.

The cleaned dataset is now ready for further analysis.
